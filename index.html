プライバシーポリシー（kironazo uploader）

最終更新日：2026年10月15日（YouTube API サービスとデータの削除の項を追加）

「kironazo uploader」（以下「本アプリ」）は、YouTube チャンネル「記録で確かめる歴史と謎」（https://www.youtube.com/@kironazo）の運営者が、自分のチャンネルに動画を投稿・管理するためだけに使う個人用のツールです。

取得する情報

本アプリは、運営者本人の Google アカウントで YouTube Data API に接続し、運営者自身のチャンネルについて次の操作だけを行います。

  • 動画のアップロード（非公開）
  • 動画のタイトル・説明・タグ・サムネイル・字幕の設定
  • 自分のチャンネルの動画の一覧の取得

運営者以外の人の個人情報は、取得・保存・利用しません。

情報の保存

YouTube にアクセスするための認証情報は、運営者のパソコンの中にだけ保存し、外部に送信・共有しません。

第三者への提供

取得した情報を第三者に提供・販売することはありません。

YouTube API サービスの利用

本アプリは YouTube API サービスを使っています。本アプリを使うことで、YouTube の利用規約（https://www.youtube.com/t/terms）に同意したことになります。Google のプライバシーポリシーは https://policies.google.com/privacy をご覧ください。

データの保存期間と削除

本アプリが保存するのは、運営者自身のチャンネルに上げた動画の ID と、運営者のパソコン内の認証情報だけです。認証情報は、運営者が本アプリの使用をやめた時点で削除します。

本アプリの接続は、Google アカウントのセキュリティ設定（https://security.google.com/settings/security/permissions）からいつでも取り消せます。取り消すと、本アプリは YouTube にアクセスできなくなり、保存した認証情報は使えなくなります。削除の依頼は、下記のお問い合わせ先から受け付け、7 日以内に対応します。

YouTube と Google のポリシー

本アプリは YouTube API サービスを使っています。YouTube の利用規約（https://www.youtube.com/t/terms）と Google のプライバシーポリシー（https://policies.google.com/privacy）もあわせてご確認ください。

本アプリの接続は、Google アカウントの「サードパーティのアクセス」（https://myaccount.google.com/connections）からいつでも取り消せます。

お問い合わせ

YouTube チャンネル「記録で確かめる歴史と謎」の動画のコメント欄からご連絡ください。

Privacy Policy (kironazo uploader)

Last updated: October 15, 2026

"kironazo uploader" (the "App") is a personal tool used only by the operator of the YouTube channel "記録で確かめる歴史と謎" (https://www.youtube.com/@kironazo) to upload and manage videos on the operator's own channel.

Information accessed. The App connects to the YouTube Data API with the operator's own Google account and performs only the following on the operator's own channel: uploading videos (as private); setting titles, descriptions, tags, thumbnails and captions; listing the channel's own videos. The App does not collect, store or use personal information of anyone other than the operator.

Storage. Authorization credentials are stored only on the operator's computer and are never transmitted or shared with others.

Sharing. No data is sold or shared with third parties.

YouTube API Services. The App uses YouTube API Services. By using the App, you agree to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms). See also the Google Privacy Policy (https://policies.google.com/privacy).

Retention and deletion. The App stores only the video IDs of the operator's own uploads and the authorization credentials on the operator's computer. Credentials are deleted when the operator stops using the App. Access can be revoked at any time via the Google security settings page (https://security.google.com/settings/security/permissions); after revocation the App can no longer access YouTube. Deletion requests are accepted via the contact below and handled within 7 days.

YouTube and Google. The App uses YouTube API Services. See the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy). Access can be revoked at any time at https://myaccount.google.com/connections.

Contact. Please contact us via the comment section of the channel's videos.
